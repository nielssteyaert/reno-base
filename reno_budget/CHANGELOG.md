# Changelog

## 0.1.0

First release.

- Expenses with lifecycle stages, VAT, installment payments and attachments
- Categories (two levels) and rooms with optional budgets; suppliers; milestones
- Dashboard, timeline and reports: budget vs actual, spending over time, forecast, suppliers
- Excel export (full workbook, single reports, filtered expense list)
- Excel/CSV import with column mapping, value matching and preview
- Backups (manual and nightly) with restore, and a change history per Home Assistant user
